Exemplo de gradiente

Este exemplo aplicou um gradiente linear ao plano de fundo da página usando CSS. O gradiente é criado usando a propriedade `background` e a função `linear-gradient()`, que define a direção e as cores do gradiente. Neste caso, o gradiente começa com um tom de roxo, passa por um vermelho vibrante e termina com um laranja quente, criando um efeito visual atraente.

Espia o CSS pra ver como foi feito.

Este foi criado usando o https://cssgradient.io/ mas tem muitos outros para escolher gradientes prontos ou criar o seu com diferentes cores e padrões. Pesquisa aí kkkkk
