Como esse menu funciona?

Esse exemplo cria um menu escondido que aparece quando o botão é clicado.

O JavaScript usa o método addEventListener() para escutar o clique do botão.

Quando o usuário clica, o código executa: menu.classList.toggle("active")

O método toggle() adiciona ou remove a classe active.

No CSS, o menu começa com: display: none, então ele fica escondido.

Quando a classe active é adicionada, o CSS muda para: display: flex, fazendo o menu aparecer na tela.
